# 从零学习 MultiAgent-Search

这套教材面向第一次接触 Agent 开发的读者。目标是让你能解释代码为什么这样写、能定位一次任务在哪里出错，并能独立增加一个工具或小型智能体。

**主线只有一句：模型提出行动，程序执行行动，结果回到模型，系统继续运行直到完成目标。** 后面的网络接口、数据库、提示词、会话和文件操作，都围绕这条主线服务。

## 先了解教材的依据

- 编写日期：2026-11-02。以编写时的本地工作区为准，包含当时尚未提交的修改。
- 当前主智能体使用 `AsyncSqliteSaver`，由 FastAPI `lifespan` 管理连接；不要再按旧版同步 `SqliteSaver` 理解当前实现。
- 当前前端先创建会话并连接 WebSocket，再提交任务。
- 源码中的依赖锁定包括 `deepagents==0.4.3`、`langchain==1.2.10`、`langgraph==1.0.9`。在线文档可能更新，不能直接把新版本特性套进此项目。
- “当前实现”表示能从仓库代码直接确认；“教学示例”用于解释原理；“改进建议”表示尚未接入业务系统。各章会明确区分。
- 本次编写没有读取 `.env` 的秘密值，没有访问真实业务数据，没有调用付费模型、搜索或 RAG 服务。离线实验的验证结果见 [验证说明](VALIDATION.md)。

## 阅读路线

**准备亲手从零复现**：优先打开 [17 复现指南](17-rebuild-guide.md)，同时打开 [18 函数手册](18-function-handbook.md)。前者决定今天写什么，后者用于查询具体调用方式。

**完全零基础**：00 → 01 → 02 → 离线实验 01 → 03 → 04 → 05 → 06。先不急着安装所有服务。

**会一点 Python，想理解项目**：00 → 02 → 04 → 05 → 06 → 07 → 08 → 09，然后补搜索、文件和部署。

**已经跑起来，想改功能**：先读 06、07、12，再做 14 的分级作业。遇到术语回查 16。

每读一章，完成三个动作：用自己的话复述一个概念；打开对应源码找到实现；做一个实验或回答章末问题。代码阅读应以“输入、处理、输出、失败情况”四件事为中心。

## 无需密钥的配套实验

从项目根目录执行，使用 Python 3.10+ 标准库即可：

```powershell
python docs/learning/examples/01_agent_loop.py
python docs/learning/examples/02_async_context.py
python docs/learning/examples/03_state_and_paths.py
python docs/learning/examples/04_sql_grounding.py
```

这些实验使用模拟数据，**不会连接模型或网络，不会改动项目业务数据库**。模拟决策器只是便于观察流程的规则程序，不是真正的大模型。详细步骤、预期输出和挑战题见 [实验说明](examples/README.md)。

## 如何记录学习过程

把 [学习记录模板](learning-journal.md) 复制成自己的笔记。每次只改变一个变量，记录输入、观察到的事件、结果和下一步假设。不要用“感觉变聪明了”作为实验结论；改提示词后工具是否选对、是否少查一次、是否保留来源，都是更具体的判断依据。

后续源码变化时，优先检查 `create_main_agent`、`agent_lifespan`、`run_deep_agent`、`sendTask`、`ToolMonitor._emit`。教材用函数名定位，行号变化不影响检索。
